# FirstTouch — Privacy Policy

**The policy text no longer lives in this file.** It is in [`src/lib/privacy.ts`](../src/lib/privacy.ts), which the public `/privacy` page draws. That keeps one copy, so the page and this document can never disagree. To change the policy, edit that file.
